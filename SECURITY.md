# Security policy

PCTwin needs deep access to people's laptops, so we take security reports seriously.

## Reporting a problem

Use GitHub's private reporting: **Security → Report a vulnerability** on this repository. Please do not open a public issue for a security problem.

Include what you found, the PCTwin version and systems involved, and steps or a test that reproduces it. Please don't access other people's data, disrupt the service for others, or publish details before a fix is available.

## What happens next

- We acknowledge reports within **5 business days**. PCTwin is built by a small team, so this is a time we can keep.
- We confirm or rule out the problem with a reproducible test, then fix it.
- Serious fixes ship quickly through signed updates.
- We credit reporters who want credit. A paid bug bounty will follow once we can fund one.

## Scope

The PCTwin desktop app and the code in this repository.
