# Contributing to PCTwin

Thank you for your interest. PCTwin's code is open for anyone to read, use and check under the Apache License 2.0, but **we don't accept code contributions**. Pull requests from outside Creole AI Labs are closed automatically.

## Why

PCTwin handles people's entire laptops: their files, apps, settings and saved sign-ins. Every line that ships goes through our own security review, attack tests and signed release process, and we stay fully responsible for all of it. Keeping authorship in one place keeps that accountability clear.

## How you can help

- **Report bugs:** open an issue with your systems (old and new laptop), the PCTwin version and what happened. Attach a diagnostic bundle only if you've checked its contents first.
- **Suggest features:** open an issue describing what you were trying to do.
- **Report security problems privately:** see [SECURITY.md](SECURITY.md). Never in a public issue.
- **Help with translations and testing:** we'll announce how when that opens.

You're also free to fork the code under the licence. The "PCTwin" name and logo are trademarks and can't be used for a fork.
