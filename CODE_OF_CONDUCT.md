# Code of conduct

Issues and discussions here are for helping each other and improving PCTwin.

- Be respectful. No harassment, insults or discrimination.
- Stay on topic and assume good faith.
- Never post other people's personal information, or your own passwords, keys or private files.
- Report security problems privately, as described in [SECURITY.md](SECURITY.md).

Creole AI Labs moderates this repository and may hide comments, close threads or block accounts that break these rules.
