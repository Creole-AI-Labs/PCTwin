# What each place is (Engineering Plan 9.16, "What each place is"): markers and folder shapes
# that name a place, run over the mover's own record after the sweep. A label names a place for
# the screens and orders and weighs it; it never changes what is included, whose it is or where
# it lands. Compiled into the app, so it is covered by the app's own signature; a test pins its
# fingerprint, so a change to it is a change to the app.
#
# Each row: system | shape | marker | what
#   system  windows, mac, linux or any
#   shape   folder         a folder with this name
#           folder-suffix  a folder whose name ends with this (a package, such as .photoslibrary)
#           holds          a folder that directly holds a file or folder with this name
#           file-suffix    a file whose name ends with this
#   what    camera-photos, screenshots, photos-library, lightroom-catalog, music-library,
#           phone-backup, time-machine, file-history, windows-image-backup, disk-image-backup,
#           old-windows, virtual-machine-disk, disc-image, linux-on-windows, game-saves,
#           installed-games, containers, email-archive, email-cache, password-vault,
#           money-records, code-project, notes-vault, video-project, music-project, design-file,
#           ebook-library
# Names are compared ignoring case. Lines starting with # are notes. The first row that matches
# names the place.
