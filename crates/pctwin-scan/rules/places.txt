# The rules file: places whose kind is known from where they are, before anyone's access is
# looked at (Engineering Plan 9.16, "Whose is it"). A hit puts the place in that bucket and the
# sweep only counts it: one line in the report, never a list of what is inside.
#
# Each row: system | where | name | kind
#   system  windows, mac, linux or any
#   where   root     directly under the root of any drive the sweep walks
#           sysroot  directly under the root of the drive the system runs from
#           home     directly under a person's home folder
#           under    a path below a person's home folder, folders separated by /
#           any      a folder with this name anywhere
#   kind    system       part of the operating system
#           app          installed programs and what they keep for everyone
#           app-data     what one program keeps for one person (counted per program folder)
#           junk         caches, temporary files and bins
#           rebuildable  can be made again (downloaded packages, build output); counted as one item
#           keep-whole   the person's own, counted and moved as one item (a project's history)
#           old-system   an older copy of the system: the system's, except the old homes inside it,
#                        which are placed by their owners
# Names are compared ignoring case on Windows and macOS. Lines starting with # are notes.
